# Issue tracker

Use repo-local Beads through `br`. Skills' “issues” and “tickets” mean beads, not GitHub Issues or local Markdown files.

Follow the repository's Beads / br rules in the root `AGENTS.md` for the selected database, ownership, claiming, dependencies, synchronization and closure. Reuse existing beads for the same scope.

Represent readiness with native Beads status and blocking dependencies. Keep Hive's [label taxonomy](../beads-labels.md) when adapting skills; generic labels such as `ready-for-agent` are not repository labels, and no separate triage label mapping is required.
