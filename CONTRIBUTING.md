# Contributing to Hive

Read [Philosophy](./docs/PHILOSOPHY.md) for the project's scope and [AGENTS.md](./AGENTS.md) for contribution rules.

## Set up a source checkout

Follow [Beads setup](./docs/beads-integration.md#bootstrap-a-clone) for prerequisites and tracker requirements. From the canonical Hive checkout:

```sh
mise trust
mise run
```

This installs the tools and bootstraps Beads. [Repository commands](./docs/repository-commands.md#setup-and-automation) covers task discovery and the setup recipe. For individual builds, installation destinations and runtime requirements, see [CLI artifacts](./lib/tooling/README.md#cli-artifacts).

The [documentation index](./docs/README.md) routes development, architecture and integration references.
