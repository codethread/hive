# Hive 0.7.0

Changes since v0.6.3. This minor release includes breaking changes to Bee request discovery and the Beeswax workflow-skill source.

## @hive/beads

No change.

## @hive/beeswax

- **Breaking:** the optional Hive workflow skill source moved from `skills/hive` to [`lib/beeswax/skills/hive`](../lib/beeswax/skills/hive). Update saved installer URLs to `https://github.com/codethread/hive/tree/main/lib/beeswax/skills/hive`; upgrade Beeswax before using setup to install it.
- The skill content is unchanged. Existing installed copies need no migration; Beeswax sync and update leave them unchanged. Optional installation is described in `beeswax setup --help` and the [skill-only installer example](../lib/beeswax/README.md#install-a-customizable-workflow).
- Hive now adopts the skill locally through the upstream installer, retaining its project copy and generated lock entry.

## @hive/busybee

No change.

## @hive/colony

- **Breaking (Bee):** `bee list` was removed, with no replacement listing API. Update callers to use focused native Beads queries for request discovery, then pass exact request IDs to `bee status`, `bee result` or `bee stop`. Read each command's focused `--help`.
