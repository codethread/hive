# Hive 0.8.1

Changes since v0.8.0.

This release includes breaking configuration, daemon protocol and workflow changes. Read `<tool> changelog --release 0.8.1` for details and adoption actions; Bee and Colony have separate histories.

## @hive/beads

- Board projections include native ownership so Hive UI can identify human-assigned work.

## @hive/beeswax

- Prime centralizes guidance for reading ancestor descriptions and keeping child scope narrow.

## @hive/busybee

- **Breaking:** `do-feature-task` 0.2.0 and Land 5.0.0 simplify stage sequences while retaining independent review and repair loops. Inspect unfinished runs with `busybee preflight` before adopting these definitions; update callers for their new input and outcome contracts.
- Workflow authoring guidance is now independently discoverable. Update callers of the removed authoring resource as described in Busy Bee's history.
- New `blocked-review` and `in-progress-review` definitions support Colony's optional work reviews and bounded recovery. Adopting repositories must supply both definitions and their dependencies.

## @hive/colony

- Native macOS daemon startup and ownership checks work from tmux when the user's GUI launchd domain is available.
- Interrupted daemon restarts resume verification of their recorded replacement. `colony daemon restart --replace-retained` explicitly permits one further replacement within an unfinished restart, retaining its recovery evidence.
- Optional hourly reviews inspect blocked and stranded work through ordinary workflows. Hive's drone role follows the supplied workflow or private protocol.
- **Breaking:** automatic nurse audits and `auto_nurse` configuration are removed; explicit nurse advice remains available. Remove the old key before upgrading, install matching Bee/Colony executables together, and follow the Colony history for restart and policy reload actions.
- **Breaking:** daemon policy and recovery responses change. Protocol consumers must handle `autoWorkReviews` and pending `recovering` responses.
- Reconciliation waits five seconds between passes, reducing background polling. Restart the daemon after upgrading to apply the new delay.

## @hive/hive-ui

- Tasks whose populated owner and assignee match appear in a separate top lane, once each. Family members retain links to their context.
- Workflow workshop examples follow the simplified Land chart.
- Restart the Hive UI server after upgrading and reload the browser.
