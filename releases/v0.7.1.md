# Hive 0.7.1

Changes since v0.7.0.

Colony removes recurring process-table scans and descendant-history rewrites from managed execution. It now observes the child handle and cleans up the verified supervisor process group with bounded TERM/KILL escalation. Processes that detach or create separate groups are outside managed cleanup.

**Required before upgrading:** drain or stop old attempts with the old Colony runtime, install all matching Colony companion executables, then restart the daemon and resume unfinished work. Restarting the daemon alone leaves old supervisors and their scan loops alive.

This release also moves automation protocols under `system`, adds tracker alerts and workflow exploration, and supports reviewed local feature-task delivery. Read each affected tool's `changelog` for required adoption steps.

## @hive/beads

No change.

## @hive/beeswax

- Move setup and hook automation under `beeswax system`. Required: follow `beeswax changelog` to update tracker hooks, project contracts, custom callers and checkout bindings, then load and trust changed harness adapters.
- Expose tracker alert status/wait and manual recovery guidance, with advisory hold and clearance notices in managed harness adapters.

## @hive/busybee

- Move driver admission to `busybee system prepare-driver`; upgrade Bee, Busy Bee and Colony together and update custom callers.
- Add saved workflow inspection, checkpoint reads and temporary outcome simulation.
- Add the repository's `do-feature-task` workflow for reviewed integration into a pinned local feature base. Installing the CLI alone does not install the workflow or its role configuration.
- Dispatch Land 4.1 reviews to the `reviewer` Bee kind; adopting this definition requires that kind and available Colony execution.

## @hive/colony

- Replace recurring scans with owned-group supervision; follow the coordinated upgrade steps above.
- Read retained supervisor identity and token independently of discarded process-history fields, so retained attempt and assessment artifacts remain usable for cleanup.
- Send observer reports through Bee's `system` protocols. Update custom observer prompts alongside matching executables.
- Scope `colony explain` to the selected request. JSON consumers must use `runtime.result.value.attempts` instead of `runtime.result.value.colony.attempts`; refresh the daemon for the new socket command.
- Bee moves workflow dispatch and observer submissions under `bee system` and adds Hive's optional read-only Architect kind.

## @hive/hive-ui

- Explore saved workflows with a local canvas, nested navigation, published instructions and temporary outcome simulation.
- Poll saved checkpoints without rebuilding unchanged diagrams; preserve view state on refresh.
- Required: upgrade Busy Bee alongside Hive UI for its matching preview, checkpoint and simulation interfaces.

## @hive/honeycomb

- Add pinned local feature-base integration and containment-verified cleanup for reviewed task delivery.
