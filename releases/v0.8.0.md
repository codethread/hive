# Hive 0.8.0

Changes since v0.7.1.

Read `<tool> changelog --release 0.8.0` for detailed changes and adoption actions.

## @hive/beads

**No change.**

## @hive/beeswax

- **Breaking:** Beeswax now manages Scent identity hooks and the Pi loader for selected harnesses, alongside onboarding and tracker alerts.
- Upgrade the matching Hive suite, remove old source hooks, explicit Pi Scent registrations and the optional Codex Scent plugin, then run `beeswax update --yes` in each adopting checkout. Review and commit generated files; restart the harness and review/trust its hooks or extensions. `beeswax sync` retains the accepted version.

## @hive/busybee

- **Breaking:** default run views omit actor context and instruction bodies. Read native run/task briefs for work details; use `busybee show --help` for instruction expansion and update consumers of the omitted fields.
- Collection follows deliberately resumed cancelled stages without replacing the saved run. Upgrade Busy Bee and Bee together to use this recovery path.

## @hive/colony

- Optional automatic nurse audits review batches of 25 new assessment reports, retaining unfinished coverage for recovery. Activation requires the updated nurse role and Colony runtime; follow `colony changelog --release 0.8.0` for configuration and restart guidance.
- Bee can deliberately resume cancelled assignments with `bee retry --resume-cancelled`, preserving the original request's history and workflow assignment.
- Managed drivers use focused native brief reads and compact Busy Bee views. Bee and Colony retain separate changelogs.

## @hive/hive-ui

- Bead details render Markdown with readable tables and bounded long links.
- Refresh feedback stays out of the board layout; dismissible error toasts work with dialogs open, and sidebar controls remain available on small screens.
- Warm refreshes reuse unchanged workflow metadata and share overlapping annotation reads, preserving source times and visible failures.
- Restart the Hive UI server after upgrading and reload the browser.

## @hive/honeycomb

**No change.**

## @hive/qlock

**No change.**

## @hive/scent

- Scent becomes a public installed executable with offline release history. It supplies Claude Code and Codex hooks and a Pi extension without requiring Hive sources, application dependencies or Bun on the harness PATH.
- Claude Code session hooks preserve supplied Bee identities; native children receive their own explicit actors without changing the parent environment.
- **Breaking:** source hook entry points and the optional Codex plugin are removed. Adopt Beeswax-managed integration as described above.

## @hive/shared

- Shared contracts support automatic nurse policy and replacement provenance for cancelled requests. Consumer changes appear in the Bee, Colony and Busy Bee histories.

## @hive/tooling

- Release preparation now generates Scent's structured history from declared tool records.

## @hive/waggle

**No change.**

## hive

- All workspace packages share version 0.8.0. Repository onboarding and release guidance now cover installed Scent integration and adoption.
