# Hive 0.6.0

Initial suite release. These highlights cover all 184 commits through `0497db1aa31dfcd4d166d95602dc9a188c77e1f3`; there is no previous reachable stable suite tag. The [full history](https://github.com/codethread/hive/commits/0497db1aa31dfcd4d166d95602dc9a188c77e1f3/) retains individual changes, including development and repository maintenance.

## hive

- One suite version covers the root package and all 11 workspace packages. Distribution targets macOS and Linux on ARM64 and x64.
- Each platform archive contains `beeswax`, `honeycomb`, `bee`, `colony`, `colony-runtime`, `colony-worker`, `colony-watchdog`, `busybee`, `qlock` and `hive-ui`. The Homebrew formula requires Git, Beads (`br`) and Beads Viewer (`bv`).
- Installation and repository setup are separate: installing binaries creates neither a tracker nor a service. See the [installation guide](https://github.com/codethread/hive/blob/0497db1aa31dfcd4d166d95602dc9a188c77e1f3/docs/releases.md#homebrew-installation) for the tap and project prerequisites.

## @hive/beeswax

- Centralizes repository setup, permanent Beads tracker configuration, snapshot synchronization, JSONL merging, Git hooks and executable installation.
- Adds repository-local onboarding for Claude Code, Codex and Pi. `beeswax prime` supplies tool guidance offline; generated harness adapters load it while preserving unrelated settings.
- Setup reports configured artifacts, pending execution checks and completed phases after partial failures. Source/provenance discovery and effective Honeycomb configuration help users inspect an installation. These onboarding improvements are part of [d7e55e9](https://github.com/codethread/hive/commit/d7e55e9fb000d05b255240210a7df3694c0447df).
- Adds explicit, history-preserving Git packing.

## @hive/honeycomb

- Manages regular and pooled Git worktrees with repository-local configuration, selectable setup commands, structured JSON results and terminal navigation.
- Adds a worktree tree grouped relative to the default branch, with inferred feature ancestry. Pooled creation prepares only the selected slot; inventory reads leave unused slots untouched.
- Adds offline Git operation and bootstrap-skip options for worktree creation, responsive picker previews and clean picker cancellation.
- Checks integration conflicts before changing the canonical worktree. Squash finish requires an explicit title and retains source commit messages in the commit body.

## @hive/colony

- Bee opens configured roles interactively or submits Busy Bee workflow assignments. Colony schedules requests across repositories with priority, capacity limits and configurable ranking.
- Adds dedicated, immutable authored responses with explicit corrections, alongside request inspection, retry, cancellation and failure acknowledgment. An answer remains distinct from task completion and request outcome.
- Adds native launchd/systemd supervision for the shared daemon, restart recovery of verified surviving executions, socket ownership checks and refreshed idle inventory. Repository membership can be awake, asleep or temporary.
- Preserves explicitly supplied tool and harness configuration paths when registering native services, including `PATH`, `CODEX_HOME` and XDG locations. Restarting from the intended environment applies changed paths; credential files stay in their existing locations.
- Adds operation history, request-progress diagnostics, health notifications, inactivity review and advisory post-run assessments. Harness choices and configuration schemas are discoverable from the CLI.

## @hive/busybee

- Runs repository-owned XState workflows as Beads tasks, supporting branching, loops, nested work and parallel joins. Generated work stays beneath its run and source task.
- Supports driver-handled and Bee-dispatched stages, saved outcomes and collection after interrupted delivery. Compatible definitions can resume existing runs; preflight reports compatibility limits before an update.
- Bundles the `do-work` definition and offline execution/authoring guidance. Initialization reports missing workflow dependencies and supports a workflow-local dependency manifest; catalogue discovery skips installed dependency directories.
- Exposes saved workflow state for inspection and Hive UI previews.

## @hive/hive-ui

- Provides a local, read-only Beads board and Bee request views, with filters, saved views, responsive layouts, hierarchy outlines and graphs.
- Displays native policy statuses, assignment, design, notes, comments and linked merge requests. Cards load before optional request details; activity indicators attach only to matching Bee requests.
- Previews saved Busy Bee workflows in a Stately modal. The hosted diagram requires network access and sends structural workflow state to Stately; the [preview guide](https://github.com/codethread/hive/blob/0497db1aa31dfcd4d166d95602dc9a188c77e1f3/lib/hive-ui/README.md#workflow-preview) describes the disclosure.
- Discovers registered repository/database pairs from an already-running Colony daemon at startup. Explicit endpoint lists remain available for offline use.

## @hive/qlock

- Serializes local commands with ordered tickets, urgent admission and repository/branch merge queues.
- Retains tickets after admission-wait timeouts so callers can resume their place. The timeout bounds waiting, not child execution; child output and exit status pass through.
- Provides structured queue status and bundled offline guidance.

## @hive/scent

- Adds native Pi and Codex integrations for session-derived agent identity and attribution, preserving identities supplied by Bee.
- Configured from a source checkout, separately from Beeswax onboarding; Scent is not a standalone executable in the release archives. See the [integration guide](https://github.com/codethread/hive/blob/0497db1aa31dfcd4d166d95602dc9a188c77e1f3/lib/scent/README.md).

## @hive/waggle

- Adds repository-owned choice classifiers to direct review attention, with discoverable definitions and structured evidence input.
- Remains a development tool, excluded from release archives. Classifier execution requires provider credentials and sends the supplied evidence to the provider; see the [usage guide](https://github.com/codethread/hive/blob/0497db1aa31dfcd4d166d95602dc9a188c77e1f3/lib/waggle/README.md).

## @hive/beads

- Adds typed native Beads operations and an in-memory adapter for behavior tests, covering claims, queries, relationships, comments and closure while retaining native Beads semantics.

## @hive/shared

- Consolidates the identity, spawn-request, response, Colony and workflow-preview contracts used across Hive's tools.

## @hive/tooling

- Separates local CLI builds from executable installation and adds suite-wide version preparation, immutable source builds, archive checksums and Homebrew formula generation.
- Adds a four-platform native candidate verification workflow in [0497db1](https://github.com/codethread/hive/commit/0497db1aa31dfcd4d166d95602dc9a188c77e1f3). It builds archives once, verifies those same bytes on matching hosts and retains identity, dependency and smoke-probe evidence for publication.
- Adds changed-test selection and timing reports, native Beads contract checks and repository quality gates for development.
